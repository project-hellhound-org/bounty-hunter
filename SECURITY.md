# Security Policy

## Reporting a Vulnerability

We take the security of the Hellhound framework seriously. If you discover a security vulnerability in the framework's core engine, modules, or the Universal Rendering Engine, please follow these steps:

1.  **Do not open a public issue.** This could expose users to risk.
2.  **Contact the maintainers directly.** Send an email to the Lead Maintainer (@l4zz3rj0d) or reach out via secure channels.
3.  **Provide a reproduction POC.** Include steps to reproduce the issue and any relevant logs.

## Response Timeline

We aim to:
- Acknowledge your report within **24 hours**.
- Provide a fix or mitigation within **72 hours** for critical vulnerabilities.
- Publicly attribute the discovery to you (if desired) after a patch is released.

## Scope

This policy applies to:
- The Hellhound-Pentest repository.
- Official modules in the `hellhound/modules/` directory.
- The `install.sh` and `update.sh` scripts.

*Thank you for helping keep the Hellhound ecosystem secure.*
